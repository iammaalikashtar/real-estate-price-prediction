# Real Estate Price Prediction

## Project Overview

This project uses Machine Learning to predict house prices based on different features of a property.

The goal of this project is to build a regression model that can learn the relationship between property characteristics and their prices and then predict prices for new properties.

---

## Objectives

- Analyze the real estate dataset
- Clean and preprocess the data
- Perform exploratory data analysis (EDA)
- Apply feature engineering
- Convert categorical features into numerical features
- Train a Machine Learning model
- Evaluate the model's performance
- Compare actual and predicted house prices
